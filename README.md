# WordQuest – MIPS Assembly Word Search Game

## About
WordQuest is a console-based word search game developed using MIPS Assembly Language and tested in MARS Simulator.

## Features
- Interactive game menu
- Find hidden words using row and column coordinates
- Horizontal and vertical word selection
- Score tracking
- Hint system
- Lives and wrong-answer feedback
- Final score and remaining words display

## Technologies Used
- MIPS Assembly Language
- MARS MIPS Simulator

## How to Run
1. Download and install MARS Simulator.
2. Open `wordquest.asm` in MARS.
3. Click Assemble.
4. Click Run.
5. Select an option from the game menu.

## Game Instructions
- Select Find Word to search for a hidden word.
- Enter the starting and ending row and column.
- Select Hint to receive a clue.
- Select Exit to finish the game.
